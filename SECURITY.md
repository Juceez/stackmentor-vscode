# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue.

Use GitHub's private vulnerability reporting feature from the repository's
**Security** tab when it is available. If private reporting is not enabled,
email [support@stackmentor.dev](mailto:support@stackmentor.dev) before sharing
details publicly.

When reporting a vulnerability, include:

- the affected component and version or commit;
- steps to reproduce the issue;
- the possible security impact; and
- any suggested mitigation, if known.

Please remove passwords, access tokens, student code, chat history, course
materials, school information, and other personal or confidential data from
the report. If such data is necessary to demonstrate the issue, explain that
privately rather than posting it publicly.

## Scope

This policy covers the StackMentor VS Code extension. Vulnerabilities in a
separately hosted StackMentor service should also be reported privately; do
not include customer or student data in the report.

We will acknowledge reports when possible, investigate their impact, and
coordinate disclosure and fixes with the reporter.

## Supported versions

The latest published extension version is the primary supported version.
Older versions may not receive security fixes, so update the extension before
confirming whether an issue still exists.
