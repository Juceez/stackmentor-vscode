# Support

StackMentor is currently maintained as a public repository and is not a
general-purpose community support project. Use the channel that matches your
request:

- For private support, including account, billing, school, or hosted-service
  problems, email [support@stackmentor.dev](mailto:support@stackmentor.dev).

- For a reproducible extension problem, open a GitHub issue with a clear bug
  description.
- For a proposed improvement, open a GitHub issue describing the problem and
  the behavior you would like to see.
- For questions about using the extension, check the extension
  [README](README.md) first, then open a clearly described GitHub issue if the
  answer is not documented.
- For a suspected security vulnerability, follow [SECURITY.md](SECURITY.md).
  Do not use a public issue.
- Do not post personal, student, or payment information in this repository.

## What to include in an issue

Include only the information needed to reproduce the problem:

- extension version;
- VS Code version;
- operating system;
- the steps you followed;
- what you expected to happen; and
- what actually happened, including relevant redacted logs.

Before posting, remove API URLs that contain secrets, access tokens, student
code, chat messages, course materials, email addresses, and school or billing
details.

Please search existing issues first and use a separate issue for an unrelated
problem.
