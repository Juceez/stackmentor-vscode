# Support

StackMentor is currently maintained as a public repository and is not a
general-purpose community support project. The repository is public for
transparency, but GitHub Issues and pull requests are disabled. External code
contributions are not accepted. Use the channel that matches your request:

- For private support, including account, billing, school, or hosted-service
  problems, email [support@stackmentor.dev](mailto:support@stackmentor.dev).

- For extension problems or questions, check the [README](README.md) first,
  then email [support@stackmentor.dev](mailto:support@stackmentor.dev) if the
  answer is not documented.
- For a suspected security vulnerability, follow [SECURITY.md](SECURITY.md)
  and use the private reporting or email option described there.
- Do not post personal, student, or payment information in this repository.

## What to include in a support request

Include only the information needed to understand the problem:

- extension version;
- VS Code version;
- operating system;
- the steps you followed;
- what you expected to happen; and
- what actually happened, including relevant redacted logs.

Before sending a request, remove API URLs that contain secrets, access tokens, student
code, chat messages, course materials, email addresses, and school or billing
details.
